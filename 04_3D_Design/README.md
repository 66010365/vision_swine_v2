# VISION SWINE — 3D Mounting System

ชุดไฟล์ส่งมอบงานออกแบบเคสและชุดติดตั้งกล้อง AI สำหรับโครงการ VISION SWINE (การนับจำนวนและประเมินน้ำหนักสุกรด้วยกล้อง AI)

**สถานะ:** ต้นแบบ 3D CAD (CAD Prototype) ณ วันที่ 26 พฤศจิกายน 2569  
**โปรแกรมที่ใช้พัฒนา:** Autodesk Fusion  
**ฮาร์ดแวร์อ้างอิง:** NVIDIA Jetson Nano Developer Kit B01 และกล้อง ELP-USB4K02AF-KL100W

> **ข้อจำกัดสำคัญ:** ชุดนี้ผ่านการตรวจสอบเรขาคณิตตามขอบเขต CAD ที่กำหนดเท่านั้น ยังไม่ผ่านการทดสอบความแข็งแรง การรับน้ำหนัก หรือการติดตั้งจริง และยังไม่ได้รับอนุมัติให้ผลิตหรือใช้งานเหนือโรงเรือน

## 1. ภาพรวมและวัตถุประสงค์

ชุดติดตั้งนี้ออกแบบเพื่อรวมบอร์ด Jetson Nano และกล้องให้อยู่ในชุดเดียวกัน โดยกล้องหันลงพื้นสำหรับระบบตรวจจับสุกร เคสมีฝาปิด แผงพอร์ต และช่องระบายอากาศ แยกชิ้นส่วนเพื่อให้สามารถถอดประกอบและพัฒนาต่อได้

มีชุดประกอบให้เลือก 2 รูปแบบ โดยใช้เคส ขายึดกล้อง แผ่นฐาน และ Adapter ร่วมกัน

| รูปแบบ | โมเดลชุดประกอบ | ขนาดคานอ้างอิง |
|---|---|---|
| คานสี่เหลี่ยม | `VISION_SWINE_Full_Assembly_V1` | 50 × 50 มม. |
| คานกลม | `VISION_SWINE_Round_Beam_Full_Assembly_V1` | เส้นผ่านศูนย์กลางภายนอก 50 มม. |

- ไม่ส่งออกบอร์ด กล้องจำลอง คานจำลอง สกรู นอต แหวนรอง อินเสิร์ต หรือแผ่นยางเป็น STL ในชุดนี้ ฮาร์ดแวร์และแผ่นยางเป็นชิ้นส่วนที่ต้องเลือกหรือจัดหาตามข้อกำหนดจริง
- ควรตรวจขนาด จำนวนชิ้นส่วน ความสมบูรณ์ของ Mesh และทดสอบเปิดไฟล์ที่ Export ก่อนนำไปใช้งาน

## 5. วิธีเปิดโมเดลและพัฒนาต่อ

### 5.1 เปิดไฟล์โมเดล

1. เปิด Autodesk Fusion แล้วใช้คำสั่ง File → Open หรือ Upload ไฟล์จากคอมพิวเตอร์เข้าสู่โปรเจกต์
2. เลือกไฟล์ Fusion Archive ใน `Exports/01_Fusion/` โดยเริ่มจาก Full Assembly ที่ต้องการ
3. ตรวจดู Component ใน Browser และหมุนมุมมอง Isometric, Front และ Bottom เพื่อตรวจตำแหน่งชิ้นส่วน
4. หากต้องการแก้แบบ ให้บันทึกสำเนาเป็นรุ่นใหม่ก่อน เพื่อรักษาไฟล์ส่งมอบต้นฉบับ
5. สำหรับโปรแกรม CAD อื่น ให้นำเข้าไฟล์จาก `Exports/02_STEP/` โดยไฟล์ STEP อาจไม่มีประวัติการสร้างหรือ Timeline แบบเดียวกับ Fusion

โปรแกรมที่ใช้ระหว่างพัฒนาคือ Autodesk Fusion บน Windows (รุ่นที่ใช้งานในช่วงพัฒนา 2706.1.17) ผลการทำงานกับรุ่นอื่นยังไม่ได้ทดสอบ

### 5.2 Source Code และการรันสคริปต์

สคริปต์เป็น Python ที่ใช้ Autodesk Fusion API ต้องรันภายใน Fusion ไม่ใช่โปรแกรม Python แบบ standalone โดยทั่วไปแต่ละโฟลเดอร์มีไฟล์ `.py` และ `.manifest` ให้เก็บไว้ด้วยกัน

วิธีเพิ่มสคริปต์:

1. เปิดเอกสารต้นทางที่สคริปต์นั้นต้องใช้ใน Fusion
2. กด `Shift + S` หรือไปที่ Utilities → Scripts and Add-Ins
3. เลือก Scripts → `+` → Script or add-in from device แล้วเลือกโฟลเดอร์ของสคริปต์
4. เลือกชื่อสคริปต์และกด Run
5. ตรวจโมเดลและรายงาน JSON ก่อนบันทึก ไม่ควรบันทึกทับต้นฉบับโดยอัตโนมัติ

สคริปต์ที่เคยเพิ่มแล้วสามารถเลือก Run จากรายการเดิมได้ โดยไม่ต้องเพิ่มใหม่ทุกครั้ง

| กลุ่ม | โฟลเดอร์สคริปต์ |
|---|---|
| สร้างชิ้นส่วนหลัก | `CreateJetsonCaseV5`, `CreateCameraMountV3`, `CreateMountingLayoutV1`, `CreateMountingPlateV3`, `CreateAdapterV1`, `CreateBeamClampV1`, `CreateRoundBeamClampV1` |
| สร้างชุดประกอบ | `CreateFullAssemblyV1`, `CreateRoundBeamFullAssemblyV1` |
| สนับสนุนและตรวจสอบ | `CreateMountingPlateV2`, `InspectJetson`, `DiagnoseJetsonReferenceV1`, `RecoverJetsonReferenceV1` |
| ประวัติการพัฒนา | `CreateCameraMountV1`, `CreateCameraMountV2`, `CreateJetsonBottomCase`, `CreateJetsonCaseV2`, `CreateJetsonCaseV3`, `CreateJetsonCaseV4`, `CreateMountingPlateV1` |

**ข้อควรระวังเกี่ยวกับการรันสคริปต์:**
- สคริปต์บางตัวใช้ชื่อเอกสารหรือ Component เฉพาะ และต้องเปิดเอกสารต้นทางก่อนรัน เช่น `CreateFullAssemblyV1` ใช้โมเดลต้นทาง 6 ชุด และ `CreateRoundBeamFullAssemblyV1` ใช้ Full Assembly คานสี่เหลี่ยมร่วมกับ Round Beam Clamp V1
- สคริปต์บางตัวต้องใช้ไฟล์ STEP อ้างอิง รายงาน JSON หรือสคริปต์รุ่นก่อนหน้า จึงเก็บโฟลเดอร์ Scripts ทั้ง 20 รายการไว้
- หลังจัดโฟลเดอร์รายงานใหม่ ควรตรวจสอบ Path ที่อ้างอิง `Documentation` รวมถึง Path แบบระบุไดรฟ์หรือชื่อผู้ใช้เครื่องเดิม และการอ้างอิงโฟลเดอร์ `Models` ที่เคยมีอยู่ หากจำเป็นให้ปรับ Path หรือคืนสำเนาไฟล์/โฟลเดอร์ที่ต้องใช้
- ควรตรวจความพร้อมของสคริปต์และการอ้างอิงไฟล์บนเครื่องผู้รับมอบก่อนรัน การสร้างโมเดลซ้ำจากชุดไฟล์ที่จัดใหม่ยังไม่ได้ทดสอบครบทุกสคริปต์
- ผู้รับมอบสามารถเปิดไฟล์ Fusion/STEP ที่ส่งออกไว้ได้โดยไม่จำเป็นต้องรันสคริปต์สร้างโมเดลใหม่

### 5.3 ไฟล์อ้างอิง

`Reference/Jetson_Nano_Dev_Kit_3D_b01.stp` เป็นไฟล์โมเดลบอร์ด B01 จาก NVIDIA ที่ใช้เป็นข้อมูลอ้างอิงในการกำหนดขนาด ตำแหน่งรูยึด พอร์ต และพื้นที่ของบอร์ด ไม่ใช่โมเดลที่พัฒนาขึ้นเองในโครงการ

ควรรักษาชื่อและเนื้อหาไฟล์เดิม และตรวจสอบเงื่อนไขสิทธิ์การส่งต่อไฟล์ของ NVIDIA ก่อนเผยแพร่หรือส่งมอบ รวมถึงโมเดลที่มีเรขาคณิตอ้างอิงดังกล่าวประกอบอยู่ด้วย

## 6. แนวทางการประกอบต้นแบบตาม CAD

รายการด้านล่างอธิบายลำดับที่ใช้ตรวจสอบในโมเดล ไม่ใช่คู่มือติดตั้งรับน้ำหนักเหนือศีรษะที่ผ่านการรับรอง ขนาดฮาร์ดแวร์เป็นค่าตามแบบจำลอง ต้องยืนยันกับชิ้นส่วนจริงก่อนผลิตหรือทดลองประกอบ

### 6.1 ชุดคานสี่เหลี่ยม

1. เตรียม Mounting Plate V3 และตำแหน่งเกลียวฝัง M4 ตามแบบ
2. ประกอบ Adapter V1 เข้ากับแผ่นประกบล่างฉบับที่เพิ่มรู M4 แล้ว โดยทำก่อนนำคานเข้าประกบ
3. ประกบคานระหว่างแผ่นบนและล่าง และขันชุดแกนเกลียว M8 ทั้ง 4 จุดก่อนติด Mounting Plate V3
4. จัด Mounting Plate V3 ให้ตรงกับหน้าแปลน Adapter และใช้สกรู M4×10 จากด้านบนตามแบบ
5. จัดวางเคส Jetson Nano และกล้องตาม Layout เดิม โดยให้เลนส์หันลงพื้น และจัดสายตามพื้นที่ที่กำหนด

ข้อจำกัด: หลังติดแผ่นฐานแล้ว ลูกบล็อก Ø20 มม. ไม่สามารถเข้าถึงนอต M8 ด้านล่างทั้ง 4 แกนได้ ต้องถอดแผ่นอุปกรณ์ก่อนเมื่อต้องบำรุงรักษานอตล่าง

### 6.2 ชุดคานกลม Ø50 มม.

1. เตรียม Lower Clamp และ Adapter V1 โดยยึดด้วยสกรู M4×14 จำนวน 2 ตัว จากด้านในก่อนใส่ยางและคาน
2. จัดแผ่นยางรองและคานกลมเข้ากับ Lower Clamp แล้ววาง Upper Clamp
3. ประกอบชุดสกรู M8×50 จำนวน 4 ตัว พร้อมนอตและแหวนรอง ก่อนติด Mounting Plate V3
4. จัด Mounting Plate V3 ให้ตรงกับหน้าแปลน Adapter และยึดด้วยสกรู M4×10 ตามแบบ โดยสอดเครื่องมือเข้าจากด้านข้างใต้คาน (−Y และ +Y ตามตำแหน่งรู) ไม่ลดเครื่องมือลงจากเหนือคานโดยตรง
5. จัดวางเคสและกล้องให้ตรง Layout เดิม โดยให้เลนส์หันลงพื้น

ข้อจำกัด: หลังติดแผ่นฐานแล้ว ทางเข้าลูกบล็อกของนอต M8 ล่างถูกบังทั้ง 4 จุด และการเข้าถึง M4×14 ต้องถอด Upper Clamp คาน และยางออกก่อน การสัมผัสแผ่นยางใน CAD ยังไม่ได้ยืนยันแรงบีบหรือความสามารถต้านการหมุนจริง

## 8. ข้อจำกัดและสิ่งที่ต้องดำเนินการก่อนใช้งานจริง

- ตรวจขนาดคานและอุปกรณ์จริง ความพอดีของเคส ระยะรูยึด เกลียวอินเสิร์ต และความยาวสกรู รวมถึงขนาดเกลียวของกล้องจริง
- ตรวจพื้นที่เสียบ–ถอดสาย USB และสายไฟ รัศมีดัดสาย พื้นที่มือและเครื่องมือ รวมถึงการถอดบอร์ดเพื่อซ่อมบำรุง
- ตรวจการระบายความร้อน และความเหมาะสมกับสภาพโรงเรือน เช่น ฝุ่น ความชื้น และการทำความสะอาด
- กำหนดวัสดุและวิธีผลิตที่เหมาะสม โดยเฉพาะจุดต่อรับแรงและแคลมป์ ไม่ใช้เกลียวฝังในพลาสติกเป็นเส้นทางรับน้ำหนักเพียงอย่างเดียวสำหรับการติดตั้งเหนือโรงเรือน
- ออกแบบและตรวจสอบทางรับแรงโลหะ รวมถึงสายเซฟตี้อิสระที่เหมาะสมกับน้ำหนักจริง
- ทดสอบความแข็งแรง แรงถอนอินเสิร์ต การหมุน การลื่นไถล การรับน้ำหนัก และความมั่นคงของชุดติดตั้งโดยผู้รับผิดชอบงานวิศวกรรมก่อนอนุมัติให้ผลิตหรือติดตั้งจริง
- ตรวจเปิดไฟล์ Fusion/STEP และตรวจ Mesh STL ที่ส่งออก รวมถึงตรวจการทำงานของสคริปต์หลังจัดโฟลเดอร์ ก่อนใช้เป็นชุดส่งมอบที่พร้อมนำไปพัฒนาต่อ

สถานะการอนุมัติของต้นแบบ:

```text
approved_for_print        = false
approved_for_installation = false
strength_tested          = false
```
